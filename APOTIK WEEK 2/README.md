# Jogo Sehat - REST API & Fetch API

Project ini mempertahankan website Jogo Sehat dan menambahkan tugas Week 4:

1. Connect to API menggunakan Fetch API dan parsing JSON.
2. Display API Data menggunakan DOM manipulation.
3. Handle API State: loading, success, dan error.
4. Tombol retry jika terjadi error.
5. Data diambil dari JSONPlaceholder.

Cara menjalankan:
- Buka folder di VS Code.
- Jalankan index.html dengan Live Server.
- Scroll ke bagian "Data Kesehatan dari API".
- Data akan diambil otomatis dan dapat diambil ulang dengan tombol "Ambil Data API".
